# 이유식 식단 달력

이유식 식단을 달력으로 짜고 기록하는 웹앱이에요. PC와 폰 어디서든 열고 입력할 수 있어요.

**주소:** https://seonghun-kim1648.github.io/babyfood/

## 기능

- 시기별(초기·중기·후기·완료기) 재료와 궁합을 확인하며 식단 짜기, 자동 짜기
- 끼니마다 먹은 정도·시간·양(g) 기록, 달력에 표시
- 남은 재료·토핑 재고로 끼니 바꾸기, 직접 조합 고르기
- 토핑 재고표: 소비기한(기본 14일)이 가까울수록 진한 색으로 경고

## 데이터 저장

- 기록은 비공개 저장소 `babyfood-data`의 `data.json`에 저장돼요. 이 저장소(앱)에는 개인 기록이 없어요.
- 기기마다 처음 한 번 연결해요. 설정 → 기기 연결에서 GitHub 토큰(babyfood-data의 Contents 읽기·쓰기만)을 넣거나, 이미 연결된 기기의 QR을 찍으면 돼요.
- 인터넷이 끊겨도 기기에 보관했다가 연결되면 저장해요. 두 기기에서 동시에 고쳐도 둘 다 남아요.

## 폰에 앱처럼 두기

- 아이폰(Safari): 공유 → 홈 화면에 추가
- 안드로이드(Chrome): 메뉴 → 홈 화면에 추가
